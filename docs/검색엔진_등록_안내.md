# 검색엔진 등록 안내

조현병 백과가 구글과 네이버 검색에 나오게 하는 순서예요. 계정 로그인과 소유 확인은 사이트 주인만 할 수 있어서 직접 해야 해요. 확인 코드만 받아 오면 사이트에 넣는 일은 빌드로 끝나요.

사이트 주소: `https://duscjf0098.github.io/schizophrenia-encyclopedia/`
사이트맵 주소: `https://duscjf0098.github.io/schizophrenia-encyclopedia/sitemap.xml`

## 1. 구글 서치 콘솔

1. https://search.google.com/search-console 에 구글 계정으로 들어가요.
2. "속성 추가"에서 **URL 접두어**를 고르고 위의 사이트 주소를 넣어요. (도메인 방식은 github.io 주소에서는 쓸 수 없어요.)
3. 소유권 확인 방법 중 **HTML 태그**를 골라요. `<meta name="google-site-verification" content="……">` 에서 따옴표 안의 `content` 값만 복사해요.
4. 그 값을 `tools/site-verify.json` 의 `"google"` 에 넣고 다시 빌드해서 올려요.
   ```
   node tools/build-index.cjs && node tools/build-pages.cjs
   git add -A && git commit -m "구글 서치 콘솔 소유 확인" && git push
   ```
5. 1~10분 뒤 서치 콘솔에서 "확인"을 눌러요.
6. 왼쪽 **Sitemaps** 메뉴에서 `sitemap.xml` 을 제출해요.
7. 위쪽 **URL 검사**에 첫 화면 주소와 중요한 문서 몇 개(예: `…/a/what-is-schizophrenia/`)를 넣고 "색인 생성 요청"을 눌러요.

## 2. 네이버 서치어드바이저

1. https://searchadvisor.naver.com 에 네이버 계정으로 들어가 **웹마스터 도구**를 열어요.
2. 사이트 주소를 등록해요.
3. 소유 확인에서 **HTML 태그**를 골라 `<meta name="naver-site-verification" content="……">` 의 `content` 값만 복사해요.
4. 그 값을 `tools/site-verify.json` 의 `"naver"` 에 넣고 위와 같이 다시 빌드해서 올린 뒤 "소유확인"을 눌러요.
5. **요청 → 사이트맵 제출**에 사이트맵 주소를 넣어요.
6. **요청 → 웹 페이지 수집**에 첫 화면 주소를 넣어요.

## 3. 알아둘 것

- 등록해도 검색 결과에 나오기까지 며칠에서 몇 주 걸려요. 처음에는 사이트 이름이나 문서 제목을 정확히 쳤을 때부터 나와요.
- 확인 코드는 공개돼도 괜찮은 값이에요. 비밀번호나 계정 토큰과는 달라요.
- 확인 코드를 지우면 소유 확인이 풀릴 수 있으니, 한 번 넣은 뒤에는 그대로 두세요.
- 서치 콘솔과 서치어드바이저의 "등록 계정"은 사이트에 공개되지 않아요.
- 빙(Bing)은 https://www.bing.com/webmasters 에서 구글 서치 콘솔 설정을 그대로 가져올 수 있어요.
